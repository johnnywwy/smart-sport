开发按**功能切片**推进，而不是先做完全部后端再做前端。每个切片是一条能从页面走到数据库的完整功能，包含后端任务和对应的前端任务。

### 每个后端原子任务完成后的检查

后端任务合并后，负责人立即检查：

1. 这个任务所在切片的**前端任务**是否已经可以开始（依赖的接口与契约都已就绪）？可以就当天开工。
2. 前端是否已经在用 Mock 开发？如果是，切换到真实接口联调，删除对应 Mock。
3. 后端任务如果没有前端配套（如迁移机制、缓存），在切片表中标“无前端”，无需检查。

### 切片的五个步骤

```
① 契约：在 contracts 中写好接口的 Zod schema、错误码、示例数据
② 并行：后端实现 + 集成测试  ‖  前端基于契约与 Mock（MSW）实现页面
③ 联调：前端切到真实接口，修正差异（差异只能通过修改契约解决）
④ 验收：切片的 Playwright 冒烟用例通过；种子数据中可演示
⑤ 完成：后端、前端、测试、文档在同一个切片里全部打勾才算完成
```

契约一旦合并，前端就不必等后端；后端完成后，前端当天即可联调。
