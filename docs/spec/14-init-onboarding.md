# 14 · 系统初始化与学校开通向导

## 1. 系统初始化

命令：`pnpm --filter server cli init`（容器内同名命令）。可重复执行，已存在的数据跳过。

| 步骤 | 内容                                                         | 来源                                                             |
| ---- | ------------------------------------------------------------ | ---------------------------------------------------------------- |
| 1    | 执行 public 迁移                                             | 代码                                                             |
| 2    | 同步应用、功能模块、菜单、内置角色、内置字典、编号规则       | contracts                                                        |
| 3    | 导入全国行政区划（省、市、区县）                             | `deploy/seed/regions.csv`（民政部区划代码）                      |
| 4    | 导入运动项目库与《国家学生体质健康标准》                     | `deploy/seed/sport-items.json`、`scoring-standards/*.json`       |
| 5    | 创建公司组织与预置部门（研发部、销售部、生产部、技术服务部） | 代码                                                             |
| 6    | 创建第一个超级管理员                                         | 交互输入或环境变量 `INIT_ADMIN_*`；开发环境默认 `admin / 123456` |
| 7    | 创建当前学年与学期                                           | 按当前日期推算                                                   |

开发环境额外命令 `cli seed-demo`：演示教育局（省、市、区）、代理商（含部门）、3 所学校（小学、九年一贯制、大学各一）、班级学生教师、各身份演示账号（密码 `123456`）、一个多身份账号。

## 2. 学校开通向导

入口：机构管理 → 学校开通（`platform:onboarding`）。

| 步骤               | 填写                                               | 说明                                                     |
| ------------------ | -------------------------------------------------- | -------------------------------------------------------- |
| ① 学校信息         | 名称、学校标识码、所在区划                         | 标识码查重                                               |
| ② 学校档案         | 学段（多选）、各学段年限、公办 / 民办              | 默认 6-3-3-4                                             |
| ③ 服务与应用       | 试用或合同（合同编号、服务期）、开通应用、负责销售 | 合同开通生成审核待办；试用直接生效                       |
| ④ 开通学校库       | —                                                  | 后台任务，显示进度；失败可单独重试                       |
| ⑤ 首个学校管理员   | 姓名、手机号或用户名、邮箱（可选）                 | 已存在账号则追加身份；生产环境生成随机初始密码并展示一次 |
| ⑥ 导入数据（可选） | 班级、学生、教师                                   | 复用 ImportWizard；也可稍后由学校自行导入                |

- 向导每一步可保存草稿（`onboarding_drafts`），关闭后继续。
- 完成后生成开通记录，写审计，通知负责销售。

## 3. 接口

| 方法  | 路径                     | 说明                 |
| ----- | ------------------------ | -------------------- |
| POST  | `/onboarding`            | 创建草稿             |
| PATCH | `/onboarding/:id`        | 保存某一步           |
| POST  | `/onboarding/:id/submit` | 提交（触发开通任务） |
| GET   | `/onboarding/:id`        | 查看进度             |

## 4. 验收标准

- 在空数据库上执行 `init` 后，可用超级管理员登录并看到全部系统应用。
- 重复执行 `init` 不产生重复数据。
- 向导完成后，学校管理员可登录、选择该学校、进入“基础信息”模块的工作台，并看到已授权的学校数据菜单。
- 第 ④ 步失败时，重试成功后向导继续，不需要重填前面步骤。
