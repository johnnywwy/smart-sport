# 13 · Web 后台

> 页面长什么样以设计稿为准（“智慧体育云后台设计稿”画布）。本文件写清路由、外壳、页面清单和流程，供前端实现。
> 其他文档里的“门户”一词，指本文件的“选择模块”页；“应用工作区”指“模块工作区”。

## 1. 页面流

```
/login ──> (/change-password) ──> /select-org（多身份时） ──> /modules（多模块时） ──> /m/:moduleCode/...
```

| 路由                       | 页面           | 说明                                                                                                                           |
| -------------------------- | -------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| `/login`                   | 登录           | 左侧图形，右侧账号 + 密码；失败 5 次出现图形验证码；“忘记密码”走邮箱验证码                                                     |
| `/change-password`         | 强制改密       | `mustChangePassword` 时进入，改完继续                                                                                          |
| `/select-org`              | 选择组织       | 按组织类型分组的身份卡片；上次使用的排第一；不可用的身份置灰并说明原因。只有一个身份时跳过                                     |
| `/modules`                 | 选择模块       | 一行 4 张模块卡片（图标、名称、一句说明、菜单预览）；数据来自 `GET /modules/available`。只有一个可用模块时跳过，直接进入该模块 |
| `/m/:moduleCode/*`         | 模块工作区     | 左侧是该模块的“分组 → 菜单”；路由由菜单生成                                                                                    |
| `/m/:moduleCode/workbench` | 工作台         | 每个模块侧栏的第一项，也是进入模块后默认打开的页面。指标卡、待办、最近访问（见第 2 节）                                        |
| `/403` `/404`              | 无权限、不存在 |                                                                                                                                |
| `/upgrade-browser`         | 浏览器版本过低 | 入口脚本检测，不满足基线直接跳转                                                                                               |

M1 的模块：`base` 基础信息、`platform-admin` 平台管理（仅公司）。分组与菜单的完整清单见 spec 04 第 3.1 节。

## 2. 工作台

工作台是每个模块侧栏的第一项（在分组之上，不属于任何分组），进入模块后默认打开。它登录即可用，不需要单独的权限；页签栏里的“工作台”页签不能关闭。各模块的工作台结构相同，指标卡按“当前身份 + 当前模块”取：基础信息模块见下表，平台管理模块显示开通与服务相关的指标，以后的运动模块各自声明。

- **指标卡**（按身份、按数据范围统计）：

| 身份    | 卡片                                                          |
| ------- | ------------------------------------------------------------- |
| company | 负责学校数；试用中 / 30 天内到期 / 宽限期学校；待审核开通申请 |
| bureau  | 辖区学校数；已开通平台学校数；按区县开通情况                  |
| agent   | 授权学校数与即将到期的授权；本部门负责学校                    |
| school  | 班级、学生、教师数；学年升级状态；待确认转学                  |
| teacher | 任教班级与学生数                                              |

- 指标卡显示当前值、与上周相比的变化、近 30 天迷你趋势；点击跳转到对应列表（已带好筛选）。接口 `GET /portal/kpis?module=` 一次返回当前身份在该模块的全部指标。
- 待办与最近访问：最近 5 条待办；最近打开过的 5 个页面（本地记录）。
- 外壳与模块内其他页面完全相同，左侧就是当前模块的菜单，“工作台”为选中状态。待办、任务、消息从顶栏进入，不占侧栏。

## 3. 模块工作区外壳

所有模块内页面共用一个外壳（`AppLayout`）。

| 区域     | 内容                                                                                                                                                                   |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 侧栏顶部 | 产品名“智慧体育云平台”                                                                                                                                                 |
| 侧栏中部 | 第一项固定是“工作台”；下面是当前模块的菜单：一级是小号灰色分组标题（不可点），二级是菜单项（图标 + 名称，可带数字角标）。数据来自 `GET /menus/current?module=`         |
| 侧栏底部 | 切换模块：显示当前模块名，点击弹出可用模块列表与“查看全部模块”                                                                                                         |
| 顶栏左   | 侧栏折叠按钮（左缘与主内容区左缘对齐）+ 面包屑“模块 / 菜单 / 子页面”                                                                                                   |
| 顶栏右   | 学年学期选择（默认当前学期）、待办铃铛、切换组织（下拉列出全部身份 +“查看全部组织”，选择后进入新身份的选择模块页）、头像菜单（个人资料、修改密码、登录设备、退出登录） |
| 主内容区 | 白色圆角卡片。顶部是页签栏（已打开的菜单，可关闭，“关闭其他”），下面是页面                                                                                             |

- 侧栏有“展开”与“图标栏”两种模式，记住用户的选择；窄屏时变为抽屉。
- 身份标签颜色：公司蓝、教育局紫、代理商琥珀、学校绿、教师青；全站一致。
- 多校身份（company、agent、bureau）进入班级、学生、教师、学年升级等学校内菜单前，要先在“学校管理”里选中一所学校；未选择时页面提示并给出入口。选中的学校显示在页面标题旁，可以更换。

列表页的统一结构：标题与一句说明 → 右上角操作按钮（导入、导出、新增）→ 查询条件 + “查询”“重置” → 表格 → 右下角分页与每页条数。按钮高度统一 36。

反馈：新增与编辑用弹窗；成功、失败、警告用右上角提示；删除、收回、撤销等不可轻易恢复的操作用确认框并说明后果。

## 4. 通用组件

| 组件             | 说明                                                                                                                                               |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| `<Can perm>`     | 按权限码显示子元素                                                                                                                                 |
| `DataTable`      | 搜索栏、筛选、分页、排序、列设置；按权限自动显示“新增、导入、导出、批量删除”；行操作“查看、编辑、删除”按该行的 `allowedActions` 显示；“回收站”页签 |
| `SchemaForm`     | 由 Zod schema 生成表单校验；提交自动带 `version` 与幂等键                                                                                          |
| `ImportWizard`   | 上传表格 → 核对数据 → 导入结果（见 5.2）                                                                                                           |
| `StepFlow`       | 多步流程的外框：步骤条、上一步 / 下一步、完成页。学校开通、学年升级、转学共用                                                                      |
| `ScopePicker`    | 按组织类型切换单位：区域树 / 学校搜索 / 年级格子 / 学院列表；右侧实时合计                                                                          |
| `MaskedField`    | 脱敏显示，有权限者点击查看                                                                                                                         |
| `VersionWatcher` | 发现新版本时提示刷新                                                                                                                               |
| `ErrorBoundary`  | 捕获渲染错误并上报（P1）                                                                                                                           |

所有界面不显示 UUID 与系统编码（spec 00）。

## 5. 页面清单与流程

### 5.1 基础信息模块

| 分组     | 菜单       | 页面要点                                                                                                                                                                                      |
| -------- | ---------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 组织权限 | 组织架构   | 左侧部门树（人数、拖动调整、“未分配部门”常驻）；右侧“成员 / 负责范围”页签                                                                                                                     |
| 组织权限 | 成员账号   | 账号列表（姓名、登录账号、部门、角色、状态）；右侧“分配角色”面板：所在部门、角色多选（每个角色一句说明）、保存后的效果预览、该账号在其他组织的身份（只读）。未分配部门或角色的账号醒目标出    |
| 组织权限 | 角色权限   | 左侧角色列表（内置 / 自定义标签）；右侧三步：基本信息 → 能看到哪些数据（四个选项一行）→ 每个菜单四档（不可见 / 查看 / 编辑 / 管理）+ 细调按钮；改过的格子标“已改”；右栏实时预览菜单、影响人数 |
| 学校数据 | 学校管理   | 多校身份：可见范围内的学校列表，“进入学校”设为当前学校；学校身份：本校档案与平台服务状态                                                                                                      |
| 学校数据 | 班级管理   | 行政班、教学班、院系；导入                                                                                                                                                                    |
| 学校数据 | 学生管理   | 列表、新增弹窗、导入、导出；证件号与电话默认脱敏                                                                                                                                              |
| 学校数据 | 教师管理   | 教师资料与任课安排；导入                                                                                                                                                                      |
| 学籍变动 | 学年升级   | 概览页 + 升级流程（5.2）                                                                                                                                                                      |
| 学籍变动 | 转学管理   | 申请列表（方向、对方学校、状态）+ 转入流程（5.2）                                                                                                                                             |
| 授权记录 | 代理商授权 | 已授权列表 + 授权与收回流程（5.2）                                                                                                                                                            |
| 授权记录 | 操作记录   | 本组织的操作，只读，可导出                                                                                                                                                                    |

P1：谁能访问本校数据（列出可访问本校的代理商与公司人员及其能做的事、最近 30 天访问记录）；“以 TA 的视角预览”。

### 5.2 业务流程（每一步都要有页面，不能只有入口按钮）

| 流程                             | 入口                          | 步骤                                                                                                                                | 必须有的状态                                                                                                                                          |
| -------------------------------- | ----------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| 批量导入（学生、班级、教师共用） | 列表页“导入”                  | 上传表格（下载模板、规则说明）→ 核对数据（总行数 / 可导入 / 有问题，逐行列出问题和处理办法）→ 导入结果                              | 确认前不写入；可只导入正确的行；可下载问题行；24 小时内可撤销本批新增的记录（spec 11）；在其他学校在读的学生不能导入，引导去转学                      |
| 学年升级                         | 学年升级页“开始升级”          | 升级前检查 → 升年级（预览各年级去向，可指定留级、休学的学生）→ 办理毕业（只办毕业 / 送到对口学校）→ 任课安排（跟班走 / 清空）→ 完成 | 检查项分“通过 / 建议先处理 / 不影响”；确认前不改数据；可重复执行不产生重复学籍；7 天内可整体撤回，不能撤回时说明原因（spec 08）；完成页给出后续待办   |
| 转学                             | 转学管理“发起转入”            | 查找学生（姓名 + 证件号都对上才显示，证件号脱敏）→ 填写转入信息 → 等待原学校确认 → 完成                                             | 转入方可撤回、可提醒；原学校同意或拒绝（填原因）；7 天未处理自动提醒原学校，30 天未处理自动关闭并通知发起方（spec 10）；完成后原学校记录变为只读      |
| 代理商授权                       | 代理商授权“授权代理商”        | 设置授权（代理商、到期日、各菜单档位、是否可导出、是否可看敏感信息）→ 已生效 → 收回确认                                             | 右侧实时显示“对方能做的 / 任何授权都不包括的”；到期日必填且最晚到当前学年结束，到期自动收回，到期前 7 天提醒续期；收回立即生效并要求填原因（spec 05） |
| 学校开通                         | 平台管理 › 学校开通“开通学校” | 学校信息 → 学制和年级 → 管理员账号 → 服务和模块 → 开通结果                                                                          | 中途退出保存草稿；管理员邮箱已有账号时增加身份而不是新建账号；结果页逐项显示成功或失败，失败项可重试；详见 spec 14                                    |

## 6. 状态与数据

- zustand：令牌（内存）、当前身份、当前模块、当前学校、学年学期、已打开的页签；刷新页面时用 refresh 恢复。
- TanStack Query：key 统一为 `[identityId, schoolId?, 资源, 参数]`；切换身份时 `queryClient.clear()` 并清空页签。
- 401：先尝试刷新，失败回登录；403：提示无权限；409（90002）：提示刷新后重试。

## 7. 视觉

- 前端 UI 控件必须从 HeroUI 导入，禁止原生 HTML 控件替代，也禁止引入其他 UI 组件库。纯文本与非交互语义结构标签允许使用。
- 请求成功、失败的统一通知位于页面右上角，默认 2 秒后自动消失；关闭按钮使用圆形外框。字段校验错误由字段组件展示。

- HeroUI 3 + HeroUI Pro + Tailwind 4，浅色与深色主题；整体视觉参考 HeroUI Pro 的 Analytics 仪表盘模板。
- 布局与指标卡用 HeroUI Pro；表格、表单、弹层等业务组件用 HeroUI 3 开源组件。KPI、图表等 Pro 组件按子路径导入。
- 若最终不采购 HeroUI Pro，用 HeroUI 3 组件按相同结构实现 `AppLayout`、`Sidebar`、`KpiCard`，页面结构不变。
- 页面宽度 ≥ 1280 为主要设计尺寸，最小支持 1024。

## 8. 验收标准

- 多身份账号登录后进入选择组织页，选择后进入该身份的选择模块页，只看到可用模块；只有一个模块时直接进入该模块。进入模块后先看到工作台。
- 各身份看到的分组名和菜单名一致，只是数量不同。
- 在模块内切换组织后进入新身份的选择模块页，旧数据和旧页签不残留。
- 5.2 的每个流程都能从入口走到完成页，并能走通撤回、拒绝、失败重试等分支。
- 没有导出权限的用户看不到导出按钮，直接调用接口返回 403。
- 旧版浏览器访问显示升级提示页。
