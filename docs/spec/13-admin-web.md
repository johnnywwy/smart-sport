# 13 · Web 后台

## 1. 页面流

```
/login ──> (/change-password) ──> /select-org（多身份时） ──> /portal ──> /app/:appCode/...
```

| 路由               | 页面           | 说明                                                                   |
| ------------------ | -------------- | ---------------------------------------------------------------------- |
| `/login`           | 登录           | 账号 + 密码；失败 5 次出现图形验证码；“忘记密码”走邮箱验证码           |
| `/change-password` | 强制改密       | `mustChangePassword` 时进入，改完继续                                  |
| `/select-org`      | 选择组织       | 按组织类型分组的身份卡片；上次使用的排第一；不可用的身份置灰并说明原因 |
| `/portal`          | 模块门户       | 上方：工作台卡片；下方：可用应用卡片网格                               |
| `/app/:appCode/*`  | 应用工作区     | 左侧该应用菜单；路由由菜单生成                                         |
| `/403` `/404`      | 无权限、不存在 |                                                                        |
| `/upgrade-browser` | 浏览器版本过低 | 入口脚本检测，不满足基线直接跳转                                       |

## 2. 模块门户

门户与应用工作区都使用 HeroUI Pro 的 `AppLayout`（ARCHITECTURE ADR-12）。门户不显示侧栏菜单，主区分两块：

```
┌──────────────────────────────────────────────────────────────────┐
│ 顶栏：Logo · 当前组织与身份 ▾ · 学年学期 · 任务 · 待办 · 用户   │
├──────────────────────────────────────────────────────────────────┤
│ 早上好，李销售 · 浙江销售组                                       │
│ ┌ KPI ─────┐ ┌ KPI ─────┐ ┌ KPI ─────┐ ┌ KPI ─────┐             │
│ │负责学校  │ │试用中    │ │30天内到期│ │待审核    │  ← KPIGroup  │
│ │312 ↑4   │ │12        │ │7  ↗      │ │3         │   趋势+迷你图 │
│ └──────────┘ └──────────┘ └──────────┘ └──────────┘             │
│ 我的应用                                                          │
│ ┌ 应用卡片 ┐ ┌ 应用卡片 ┐ ┌ 应用卡片 ┐                          │
│ │学校运营  │ │机构管理  │ │组织与权限│                          │
│ └──────────┘ └──────────┘ └──────────┘                          │
│ 待办（最近 5 条）              │ 最近访问                          │
└──────────────────────────────────────────────────────────────────┘
```

- **工作台指标卡**（`KPIGroup`，按身份，按数据范围统计）：

| 身份    | 卡片                                                          |
| ------- | ------------------------------------------------------------- |
| company | 负责学校数；试用中 / 30 天内到期 / 宽限期学校；待审核开通申请 |
| bureau  | 辖区学校数；已开通平台学校数；按区县开通情况                  |
| agent   | 授权学校数与即将到期的授权；本部门负责学校                    |
| school  | 班级、学生、教师数；学年切换状态；待确认转学                  |
| teacher | 任教班级与学生数                                              |

- 指标卡显示当前值、与上周相比的变化、近 30 天迷你趋势；点击跳转到对应列表（已带好筛选）。接口 `GET /portal/kpis` 一次返回当前身份的全部指标。
- **应用卡片**：图标、名称、一句说明；数据来自 `GET /apps/available`。没有任何可用应用时显示“暂无可用应用，请联系管理员”。
- **待办与最近访问**：最近 5 条待办；最近打开过的 5 个页面（本地记录）。
- 顶栏同应用工作区（无左侧菜单）。

## 3. 应用工作区外壳

| 区域   | 内容                                                                                                                                                      |
| ------ | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 顶栏左 | 应用切换器（九宫格图标，弹出可用应用）、当前应用名                                                                                                        |
| 顶栏中 | 学年学期选择（默认当前学期）；多校身份显示“当前学校”选择器                                                                                                |
| 顶栏右 | 任务（进行中数量）、待办铃铛、身份切换（下拉列出全部身份，选择后回到新身份的门户）、用户菜单（个人中心、修改密码、我的会话、退出）                        |
| 左侧   | HeroUI Pro `Sidebar`：当前应用的菜单树（`GET /menus/current?app=`）；可在“展开”与“图标栏”两种模式间切换并记住选择；窄屏时变为抽屉；顶部为应用名与应用切换 |
| 内容区 | 面包屑 + 页面                                                                                                                                             |

多校身份（company、agent、bureau）进入“学校基础数据”前需选择学校；未选择时页面提示并给出“去学校运营选择”的入口。

## 4. 通用组件

| 组件             | 说明                                                                                                                                               |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| `<Can perm>`     | 按权限码显示子元素                                                                                                                                 |
| `DataTable`      | 搜索栏、筛选、分页、排序、列设置；按权限自动显示“新增、导入、导出、批量删除”；行操作“查看、编辑、删除”按该行的 `allowedActions` 显示；“回收站”页签 |
| `SchemaForm`     | 由 Zod schema 生成表单校验；提交自动带 `version` 与幂等键                                                                                          |
| `ImportWizard`   | 下载模板 → 上传 → 预览错误 → 确认 → 结果                                                                                                           |
| `ScopePicker`    | 按组织类型切换单位：区域树 / 学校搜索 / 年级格子 / 学院列表；右侧实时合计                                                                          |
| `MaskedField`    | 脱敏显示，有权限者点击查看                                                                                                                         |
| `VersionWatcher` | 发现新版本时提示刷新                                                                                                                               |
| `ErrorBoundary`  | 捕获渲染错误并上报（P1）                                                                                                                           |

所有界面不显示 UUID 与系统编码（spec 00）。

## 6. 状态与数据

- zustand：令牌（内存）、当前身份、当前学校、学年学期；刷新页面时用 refresh 恢复。
- TanStack Query：key 统一为 `[identityId, schoolId?, 资源, 参数]`；切换身份时 `queryClient.clear()`。
- 401：先尝试刷新，失败回登录；403：提示无权限；409（90002）：提示刷新后重试。

## 7. 视觉

- 前端 UI 控件必须从 HeroUI 导入，禁止原生 HTML 控件替代，也禁止引入其他 UI 组件库。纯文本与非交互语义结构标签允许使用。

- HeroUI 3 + HeroUI Pro + Tailwind 4，浅色与深色主题；整体视觉参考 HeroUI Pro 的 Analytics 仪表盘模板。
- 布局与指标卡用 HeroUI Pro；表格、表单、弹层等业务组件用 HeroUI 3 开源组件。KPI、图表等 Pro 组件按子路径导入。
- 若最终不采购 HeroUI Pro，用 HeroUI 3 组件按相同结构实现 `AppLayout`、`Sidebar`、`KpiCard`，页面结构不变。
- 页面宽度 ≥ 1280 为主要设计尺寸，最小支持 1024。

## 8. 验收标准

- 多身份账号登录后进入选择组织页，选择后进入该身份的门户，只看到可用应用。
- 在应用内切换身份后回到新身份的门户，旧数据不残留。
- 没有导出权限的用户看不到导出按钮，直接调用接口返回 403。
- 旧版浏览器访问显示升级提示页。
