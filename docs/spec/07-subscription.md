# 07 · 学校服务与应用开通

## 1. 目标

记录每所学校的服务期与已开通的应用；服务状态和应用开通直接参与权限计算。

## 2. 数据

**school_subscriptions**

| 字段                        | 说明                                                  |
| --------------------------- | ----------------------------------------------------- |
| school_id                   | 每校一条当前记录，历史另存 `school_subscription_logs` |
| no                          | 系统编号，如 `FW-2026-000123`                         |
| contract_no                 | 合同编号，试用为空                                    |
| service_start / service_end |                                                       |
| grace_days                  | 宽限期天数，默认 30                                   |
| status                      | `trial` · `active` · `grace` · `suspended`            |
| sales_identity_id           | 负责销售                                              |

**school_apps**：`(school_id, app_code)`、`start_date`、`end_date`、`source`（contract · trial · gift）。

基础应用 `school`（学校基础数据）、`org`（组织与权限）随服务开通，不单独售卖。

## 3. 状态流转

```
trial（默认 30 天）--签约--> active --到期--> grace（只读）--宽限期结束--> suspended
grace / suspended --续约--> active
suspended --学校申请--> 导出交付后归档或销毁（spec 06）
```

- 每天 01:00（Asia/Shanghai）由 worker 计算状态；启动时补算。请求同时按当前日期计算有效状态，不能因任务延迟继续授予写权限。
- **2026-11-19 用户确认**：试用和合同到期均进入配置的宽限期；宽限天数为 0 时直接停用。到期日当天有效，次日开始宽限；宽限最后一天仍只读，再次日停用。例如 11 月 19 日到期、宽限 2 天：20–21 日只读，22 日停用。服务未开始时不可用；是否试用由合同编号是否为空区分，不用已落库的状态反推服务类型。
- 到期前 90 / 30 / 7 天给负责销售发站内消息与邮件。

## 4. 对权限的影响

| 状态           | 学校类身份                   | company / agent 进入该校 |
| -------------- | ---------------------------- | ------------------------ |
| trial / active | 按开通应用正常使用           | 同左                     |
| grace          | 只保留 view、export          | 同左                     |
| suspended      | 仅学校管理员可登录，仅可导出 | 不可进入                 |

应用未开通或已过期：该应用对应的菜单不可见；模块下没有任何可见菜单时，不显示该模块卡片；相关接口返回 403（错误码 13001）。**2026-11-19 用户确认的基础应用例外**：`school`、`org` 随学校服务开通，在宽限期保留原已授权的查看和导出入口；停用后仅具有组织管理员完整权限的学校身份保留导出能力。其他独立应用仍按自身有效期关闭，不随宽限期自动延长。未开通应用不因进入宽限期而自动获得授权。没有服务记录时按不可用处理，不自动给存量学校续期或免费开通。

导航模块与应用的映射见 spec 04 第 3.1 节，`school_apps` 仍按应用权限命名空间记录，不因前台入口合并而改名。

## 5. 接口

| 方法 | 路径                                            | 权限                            | 说明                                     |
| ---- | ----------------------------------------------- | ------------------------------- | ---------------------------------------- |
| GET  | `/subscriptions?status&expiringInDays&page`     | `platform:subscription:view`    | 按数据范围过滤（销售只看负责的）         |
| GET  | `/subscriptions/:schoolId`                      | `platform:subscription:view`    | 含应用列表与历史                         |
| POST | `/subscriptions/:schoolId/requests`             | `platform:subscription:create`  | 提交开通 / 续约 / 变更应用申请，生成待办 |
| POST | `/subscriptions/:schoolId/requests/:id/approve` | `platform:subscription:approve` | 审核通过后生效                           |
| POST | `/subscriptions/:schoolId/requests/:id/reject`  | 同上                            |                                          |
| GET  | `/schools/:schoolId/apps`                       | 登录（可见该校）                | 学校当前可用应用                         |

## 6. 规则

1. 销售（编辑档）提交申请；拥有 `approve` 动作的人审核；同一人不能审核自己提交的申请。
2. 每次状态与应用变更写 `school_subscription_logs` 与审计。
3. 状态变化后清除该校所有相关身份的上下文缓存。

## 7. 错误码

| 码    | 含义                               |
| ----- | ---------------------------------- |
| 13001 | 学校未开通该应用或已到期           |
| 13002 | 学校服务处于宽限期，仅可查看与导出 |
| 13003 | 学校服务已停用                     |
| 13004 | 不能审核自己提交的申请             |

## 8. 验收标准

- 学校服务到期后进入宽限期，学校管理员新增学生被拒绝、导出可用。
- 学校未开通应用对应的菜单不显示；没有可见菜单的模块不出现在选择模块页。
- 销售的工作台按到期时间列出负责学校。

## 9. T-070 实施边界

- 本任务提供服务列表、详情（含应用与变更历史）、可见学校的应用查询，以及内部同事务初始化和状态重算能力。开通、续约和变更的公开写接口留在 T-071/T-142；本任务不提供绕过审核的管理写入口。
- 平台服务列表只对具有 `platform:subscription:view` 的公司身份开放，并与该动作的学校范围相交；范围为“本人负责”的销售仅看到实际负责学校。按服务到期日、学校 ID 升序稳定分页；`expiringInDays` 仅查询今天至未来指定天数内到期的服务。列表不返回未开通服务的学校。
- 学校应用查询显式传 schoolId。本校身份仅查本校；公司/教育局须至少有一个学校业务权限且该权限范围包含目标校；代理商逐校授权待 T-052，当前拒绝。与停用服务有关的应用元数据允许本校管理员查询，但不借此授予业务读取能力。
- 日期输入为 `YYYY-MM-DD`，按上海零时保存为 timestamptz。试用默认天数和宽限天数在初始化时读取系统参数并固化，改默认参数不改变既有服务。合同服务必须给出合同编号和服务期；基础应用自动创建，其他应用只能来自适用于学校的代码声明。
- `school_subscriptions`、`school_apps` 均带公共字段；每校一条未删除服务、每校每应用一条未删除开通记录。历史记录保存状态及应用快照；状态变化的历史、审计、outbox（subscription.changed）同事务提交。应用/服务变更触发数据库身份版本失效，不依赖进程内缓存广播。
- 导航对学校类身份按本校服务和应用过滤，公司/教育局的全局导航不绑定某一所学校。停用管理员的基础应用导航允许以已授权的 export 动作保留对应菜单，不能将此例外扩展为 view 权限。完整逐校访问守卫、代理授权上限与年级/班级范围仍由 T-053/T-054 接入，本任务不标记其完成。
