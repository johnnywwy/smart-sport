# 架构与文档检查（2026-11-18）

检查对象：GitHub `johnnywwy/smart-sport` 的 main 分支快照（982 个文件），对照 `docs/` 全部规格。只改文档，没有改代码。

## 1. 总体结论

地基的做法是对的，而且执行得很严：

- 契约先行（`packages/contracts` 声明权限、菜单、错误码和示例），前后端共用一份。
- 依赖方向由 `.dependency-cruiser.cjs` 和 `scripts/check-ui.mjs` 自动检查，进了 CI。
- 迁移只增不改（0001–0034），软删除用部分唯一索引，手机号密文加 HMAC。
- 权限变更即时生效（身份上下文带版本），集成测试覆盖“同一令牌 403 → 200 → 403”。

主要问题不在代码质量，而在**做的顺序、文档和现状脱节、几件需要人拍板的事一直没定**。下面按严重程度排列。
