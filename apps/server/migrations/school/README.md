# 学校库迁移

学校迁移在此目录独立编号，文件名为 `NNNN_说明.sql`，只新增、不修改历史文件。
业务表由 T-090 从 `0001` 开始添加；T-061 只建立迁移机制，没有提前创建业务表。

SQL 使用 `__SCHEMA__` 占位，迁移器验证学校 UUID 生成的名称后替换为带双引号的
schema 标识符。显式限定所有学校对象；禁止 `SET search_path` 和引用 public 的外键。
每文件采用单条 SQL；多个 DDL 写入一个 `DO $migration$ ... END $migration$` 块。

`_migrations` 由迁移器管理，保存原始文件的 SHA-256、版本、文件名和执行时间，
不要在业务迁移中修改它。单校的所有待执行迁移及版本记录在同一事务完成。
