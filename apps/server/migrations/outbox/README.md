# 逐数据源投递迁移

此目录在默认和额外数据源的 public schema 分别执行，不创建平台业务表。
`0001_create_outbox.sql` 创建事件表和消费去重记录；历史由 `_outbox_migrations` 管理。
只新增迁移，不修改已执行文件；每文件一条SQL，多DDL用DO块。

`pnpm db:migrate` 先执行平台迁移，再对所有配置数据源执行此目录，最后执行学校迁移。
worker不创建这些表；新增数据源须先迁移再接收业务写入。
数据源key是消费去重来源标识，不能重命名或给同一来源配置多个别名。
事件已入队不代表已消费；目标业务效果与消费标记必须在同一事务中提交。
